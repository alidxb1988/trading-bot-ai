# Claude Trading Skills

## Installation
```bash
git clone https://github.com/tradermonty/claude-trading-skills.git
```

## Skill Categories

**Market Analysis & Research**
- Sector Analyst: cross-sector analysis, rotation patterns, relative strength
- Technical Analyst: chart patterns, indicators, support/resistance, volume
- Market News Analyst: breaking news impact, sentiment, event catalysts
- Macro Briefing: Fed policy, yield curves, inflation, employment
- Theme Detector: emerging investment themes, sector convergence
- Institutional Flow Tracker: 13F filings, dark pool activity, insider transactions

**Economic & Earnings Calendars**
- Earnings dates, revenue/EPS estimates, guidance tracking
- FOMC meetings, CPI/PPI releases, jobs reports, GDP

**Strategy & Risk Management**
- Scenario Analyzer: multi-outcome probability modeling
- Backtest Expert: historical strategy testing, performance metrics
- Portfolio Manager: allocation optimization, rebalancing, correlation
- Position Sizer: Kelly criterion, volatility-based sizing, drawdown limits
- Exposure Coach: sector/geographic exposure, concentration risk
- Options Advisor: strategy selection, Greeks, premium evaluation

**Stock Screening & Selection**
- VCP Scanner: Volatility Contraction Pattern (Minervini)
- CANSLIM Screener: O'Neil methodology, growth + momentum
- Dividend Screener: yield, payout ratio, dividend growth, aristocrats
- FinViz Integration: multi-factor screening with real-time data
- Pair Trade Finder: statistical arbitrage, correlation-based pairs

**Skill Quality & Automation**
- Skill Designer: auto-generate new trading skills
- Dual-Axis Reviewer: quality assessment of generated analysis
- Idea Miner: extract actionable ideas from research
- Data Quality Checker: validate data integrity and freshness
