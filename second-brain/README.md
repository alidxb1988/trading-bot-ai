# Diaw Trading / Gomale Group — Second Brain

This is an Obsidian vault. Open this `second-brain/` folder directly as a vault in the Obsidian app (File → Open folder as vault).

## Structure

- `Daily Notes/` — one note per day: decisions, calls, shipments, deals
- `Entities/` — profile notes for every legal entity in the group, plus contracts and banking reference
- `People/` — key contacts
- `Projects/` — active workstreams (Gomale-B2B platform, Trading Bot AI, etc.)
- `Templates/` — note templates (use with the Templater plugin)
- `Skills/` — index of Claude Code skills available in `.claude/skills/`

## Recommended Obsidian Plugins
- Templater — for daily note templates
- Dataview — to query entities/projects by tags
- Calendar — for daily note navigation

## Linking Convention
Use `[[Entity Name]]` wikilinks to connect notes. Every entity, person, and project has its own note so links resolve.

## Source of Truth
Entity, contract, and banking data here is mirrored from `.claude/skills/diaw-trading-master/references/`. If those are updated, update the corresponding notes here too.
